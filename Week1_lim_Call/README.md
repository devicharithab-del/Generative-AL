In Week 1, I implemented a basic AI-powered application using Google's Gemini model. I configured the API connection in Python and tested it by sending a text query to the model.

**Steps I followed:**

1. Set up the Python project in VS Code.
2. Generated a Gemini API key and saved it in the `.env` file.
3. Installed the required `google-genai` package.
4. Wrote Python code to access the Gemini model.
5. Executed the program and verified the AI-generated output.

**Commands used:**

cd week1-llm-call

pip install -r requirements.txt

python main.py
